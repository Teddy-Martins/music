Website accessibility

Accessibility at Piano Tutorial

Piano Tutorial is designed to make learning piano information easier to access, navigate, and understand for as many users as possible.

Keyboard and screen reader support

The website uses semantic HTML elements such as headings, navigation, sections, lists, tables, labels, buttons, and forms. This structure helps assistive technologies such as screen readers understand the organization of each page. A “Skip to main content” link is available at the beginning of every page so keyboard users can move directly to the main content without repeatedly moving through the navigation.

Interactive controls, including the mobile navigation button and form fields, have accessible labels or states. The navigation button communicates whether the menu is expanded, and the question form provides status and validation messages that can be announced by assistive technology.

Images and alternative text

Informational images used throughout the lessons include descriptive alternative text. The alternative text explains the important information shown in diagrams such as the piano keyboard groups, grand staff, C major scale, and triad diagram. This allows users who cannot see an image to understand its purpose and content through a screen reader.

Images are also placed within meaningful figures and captions where additional explanation is helpful. Decorative interface elements do not depend on images alone to communicate essential information.

Color and visual readability

The website uses a high-contrast dark text and light background for most reading content. The primary text color provides strong contrast against the site's light ivory background, helping text remain readable for users with low vision or color-vision differences.

Color is not the only way important information is communicated. Links, buttons, headings, labels, borders, and text provide additional visual or structural cues. Visible keyboard focus indicators are also provided so users can identify the currently focused link, button, or form control.

Forms and error messages

The Questions page uses labels that are directly associated with each form field, making the name, email, and question fields easier to identify with a screen reader or keyboard. The form also provides clear validation messages when information is missing or invalid.

When a field has an error, the page identifies the problem and marks the field as invalid. After submission, the form provides a live status message such as “Sending...” or a success or error message so users can understand what happened without relying only on a visual change.

Responsive and reduced-motion features

The layout is responsive and adjusts for smaller screens. On mobile devices, the navigation changes to a menu button so the site's pages remain accessible without requiring a wide screen.

The website also respects the user's prefers-reduced-motion setting. When reduced motion is requested by the operating system or browser, transitions and smooth scrolling are disabled to reduce unnecessary animation.

Accessibility testing

Accessibility tools can help identify potential WCAG issues, but automated tools cannot evaluate every accessibility requirement. For example, a tool can detect whether an image has alt text, while a person must determine whether that alt text accurately communicates the image's meaning.

For a more comprehensive evaluation, the WAVE Evaluation Tool can be used to check the website for many common accessibility issues. Manual keyboard testing and screen-reader testing can also help identify problems that automated testing may not detect.

Screen readers

Piano Tutorial is structured to work with common screen readers, including NVDA and JAWS on Windows, VoiceOver on Mac and iOS, and TalkBack on Android. Users can use their platform's keyboard shortcuts, touch controls, or gestures to move through headings, links, form fields, and other content.

Accessibility is an ongoing process. If you encounter an accessibility problem while using Piano Tutorial, please use the Questions page to let us know.
